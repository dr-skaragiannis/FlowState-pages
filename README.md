# Flowstate (Pages)

Public build output for **Flowstate** — a calm pomodoro workspace with focus timer,
task board, ambience and momentum tracking.

This repository contains only the compiled, self-contained `index.html`
(all JavaScript and CSS inlined). The application source lives in a private
repository.

## Live site

https://dr-skaragiannis.github.io/FlowState-pages/

## Notes

- Do not edit `index.html` by hand — it is generated by `npm run build`.
- `.nojekyll` disables Jekyll processing so files are served verbatim.
